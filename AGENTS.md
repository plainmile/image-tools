# Image Tools Agent Instructions

- Repository: plainmile/image-tools. Public production origin: https://image.plainmile.com/. Keep independent from plainmile/pdf-tools and the PlainMile paycheck application.
- A static bilingual English/Chinese Astro + React utility site. Image decoding, masking, resizing, compression, print layouts and ZIP export must happen entirely in the visitor's browser. Never upload, store, transmit, log or analyze visitor image bytes, pixels or filenames remotely. No accounts, API server, remote fonts, paid APIs, cloud AI, OCR or tracking scripts.
- **User-requested rule: redact-image is MANUAL-ONLY. Do not add OCR, automatic text detection, automatic masks, OCR model downloads or 'AI recognition' marketing claims to production.** A former PaddleOCR proof of concept is not production-ready and should remain closed.
- Redaction drawing modes: solid color (black, white or custom), real mosaic pixelation, real blur. Both on-screen preview and actual export must render the chosen effect. Never substitute translucent placeholder blocks for an effect. Each drawn region stores its own style and strength, so changing the tool does not unexpectedly modify old regions. Avoid drawing a later visual effect over an opaque solid cover: solid covers must take precedence.
- Solid colors must overwrite underlying image pixels completely in exported raster files. Blur and pixelation are visually useful but not suitable for sensitive secrets. Communicate this distinction clearly in both languages. Export via fresh canvas encoding to discard EXIF. Reject invalid mask geometry; ZIP export must never silently include an unredacted image. Test actual exported image pixels, not just SVG overlays.
- User photos never enter the repository; automated tests use synthetic fixtures. No personal production images in public issue reports.
- Browser safety caps on file count/bytes, source megapixels, aggregate batch pixels. Display actual output bytes and dimensions. Sanitize output filenames. Release object URLs and image bitmaps. Gracefully reject animated or unsupported input when browser formats allow.
- Keep a practical compact image editor, not a decorative startup landing page. File selection, editable canvas, effect choices, Undo/Redo and downloads visible near the top. Use mobile-friendly controls at 375px, touch-enabled drawing and localized English/Chinese strings.
- Public SEO: distinct / and /zh/ tool pages, accurate natural descriptions, unique titles, canonical and reciprocal hreflang, static sitemap, semantic headings, relevant related links. No search claims for features which do not exist. Do not claim indexed until Google Search Console confirms.
- No host Node/npm is required; use Docker/GitHub Actions. Production Compose at /opt/compose/image-tools/ and operational scripts (when needed) at /opt/data/scripts/<purpose>/. External edge Docker network; never publish host ports 80/443 or impact other containers.
- All changes on feature branches -> PR -> green unit/build/SEO/Chromium/Firefox/WebKit E2E -> merge. Production publishing after main CI; immutable SHA image to GHCR and netcup. Verify actual container SHA, public HTTPS smoke tests and live-browser E2E. Do not call a push or Docker build 'deployed'.
- CI/deploy must not expose secrets in untrusted PR runs. Production Cloudflare may auto-inject monitoring scripts; preserve Cache-Control: public, no-transform for HTML and disable analytics injection for privacy-sensitive pages.
